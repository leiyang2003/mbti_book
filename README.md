# 《四文字の、その先へ。》网页版前期原型

这是基于日文精美版和用户选定的第一套视觉方向制作的响应式网页原型。

当前包含：

- 精美版风格首页；
- 可打开的目录抽屉；
- 17 项完整日文内容：使用说明、序章、12 章、终章、30 日练习与参考文献；
- 完整目录、前后章导航、阅读进度和可切换的章节书签状态；
- Markdown 表格、列表、引文、链接和章节注释的完整呈现；
- 桌面与手机响应式布局。

内容底本为该 run 的 `manuscript/ja/`。网页项目的 `src/content/` 保存 17 份与底本逐字节一致的 Markdown 文件，共 170,434 字节。水彩图来自日文精美版已经使用的 GPT Image 2 同系列资产。

## 本地预览

```bash
npm run dev -- --host 0.0.0.0 --port 4173 --strictPort
```
