# 巻末ワーク　30日で、選択肢を一つ増やす

このワークの目標は、タイプを変えることではありません。

30日後に、ある一つの場面で、いつもの反応以外の行動を一つ選べること。それが目標です。

すべての練習をする必要はありません。一つの現実の問題を、30日間かけて小さく扱います。

記録に使える時間に合わせて、二つの方法から選んでください。

## Lite版　一日1分の四問

毎日細かく記録するのが負担なら、次の四問だけに答えます。

1. 今日、何が起きた？
2. 私は自動的にどうしようとした？
3. もう一つの行動を試した？
4. 実際に何が起きた？

「試さなかった」も記録です。試せなかった理由と、行動をさらに小さくできるかを、週に一度だけ見直します。

毎日行う必要もありません。対象の場面が起きた日だけ書けば十分です。

## Deep版　予測と結果を比べる30日

同じ困りごとが繰り返し起き、条件や回復コストまで詳しく見たいときは、以下のDeep版を使います。

### 0　扱う場面を一つ決める

次の条件を満たす場面を選びます。

- この一か月に、少なくとも二回起きた。
- 結果を少し変えたいと、自分で思っている。
- 一回の小さな実験で、仕事、収入、健康、安全、重要な人間関係に回復できない損害を生まない。
- 他人から強制された変化ではない。

たとえば、次のような場面です。

- 会議で考えがあるのに、終了後まで言わない。
- 相手の話を聞いていると、すぐ解決策を言ってしまう。
- 新しい案が浮かぶたびに計画を変え、何も完了しない。
- 最初の計画に合わない情報を見ても、変更できない。
- 一つの失敗から、「この仕事は自分のタイプに向いていない」と結論する。

### 私が扱う場面

> ＿＿＿＿のとき、私はふだん＿＿＿＿する。その結果、＿＿＿＿が起きやすい。

### 第1週　見つける

最初の一週間は、変えようとしません。

同じ場面が起きたら、次の五つを記録します。

1. **合図**：直前に何が起きたか。
2. **行動**：自分は観察可能な言葉で何をしたか。
3. **体の反応**：緊張、疲労、速さ、重さはどうだったか。
4. **短期的な利益**：その行動は何を守ったか。
5. **後の代価**：数分後、数時間後、数日後に何が残ったか。

「消極的」「優柔不断」「冷たい」などの評価語は、行動に翻訳します。

- 消極的 → 質問が浮かんだが、会議中には口にしなかった。
- 優柔不断 → 応募期限の二日前まで、候補を比較し続けた。
- 冷たい → 相手が困った経緯を聞く前に、解決手順を説明した。

第1週の成功は、変化ではありません。

「いつ、どの条件で、何をしているか」が、一回でも言えたら成功です。

### 第2週　問い直す

二週目は、その場面に欠けているものを調べます。

自分のタイプに合わせて答えないでください。次の八つをすべて見ます。

| 方向 | 問い |
|---|---|
| 外 | 本人、現場、他者から得るべき情報は何か |
| 内 | 周囲の反応から離れて、自分で考える時間はあるか |
| 事実 | 確認できたことと、推測を分けたか |
| 可能性 | まだ考えていない説明、方法、未来はあるか |
| 原則 | 何を基準に決めるか。同じ条件に同じ説明ができるか |
| 影響 | 誰の何が影響を受けるか。本人に聞いたか |
| 収束 | 何を、いつまでに決める必要があるか |
| 余白 | 何を未決定のまま残し、どの情報で見直すか |

八つの中から、この場面で最も空いている一つを選びます。

> この場面で欠けているのは、＿＿＿＿の情報/行動ではないか。

これは結論ではなく、仮説です。

### 第3週　小さく試す

三週目は、欠けているものを、一回の行動に変えます。

よい実験は、次の五つを満たします。

- **小さい**：15分以内、一文、一人、一回などに縮小できる。
- **観察できる**：「頑張る」ではなく、実行したか判定できる。
- **合図がある**：いつ実行するか、状況を決める。
- **可逆的**：結果を見て、次回やり方を変えられる。
- **自分が望んでいる**：タイプ論や他人に強制された行動ではない。

### if-thenにする

> もし＿＿＿＿という合図が起きたら、私は＿＿＿＿を一回する。

例：

- もし最初の議題で司会が意見を求めたら、準備した一文を読む。
- もし相手の話を聞いて解決案が浮かんだら、それを言う前に「今は聞いてほしい？　一緒に解決したい？」と聞く。
- もし新しい案を思いついたら、現在の最低版を15分進めてからメモする。
- もし計画と違う情報が入ったら、次の見直し日に比較する表へ追加する。

初回は、難しさが10点中3–4点になるまで小さくします。

うまく実行できなければ、意志が弱いと結論せず、行動が大きすぎないか、合図があいまいではないかを確かめます。

### 第4週　編み直す

四週目は、「できた/できなかった」で自分を採点せず、結果を行動の幅へ編み直します。

### 一回の実験記録

| 項目 | 記録 |
|---|---|
| 場面 | いつ、どこで、誰と、何が起きたか |
| 予測 | 行動すると何が起きると思っていたか |
| 実行 | 決めた小さな行動をしたか |
| 事実 | 実際に見聞きできたことは何か |
| 体験 | 気分、緊張、疲労、回復はどうだったか |
| 他者の反応 | 直接聞けた反応は何か。推測と分けたか |
| 差 | 予測と現実はどう違ったか |
| 次回 | 残すこと、小さくすること、変えることは何か |

一回でうまくいったから、その行動がどの条件で使えるかを、もう一度確かめます。

うまくいかなかったら、タイプの証明にしません。

- 行動が大きすぎたのか。
- 相手への伝え方が合わなかったのか。
- その場面に必要な力の仮説が違ったのか。
- リスク、権限、時間、健康状態など、性格以外の条件を見落としたのか。

その情報を使って、次の一回を組み直します。

### 30日後の振り返り

次の六つに答えます。

1. どの条件で、いつもの反応が出やすかったか。
2. いつもの反応は、何を守っていたか。
3. 反対側の行動を必要としたのは、どの条件か。
4. 新しい行動の中で、次回も使えるものは何か。
5. 使わないこと、他人に任せること、支援を求めることは何か。
6. 「私は＿＿だからできない」という文は、いまどう言い換えられるか。

最後に、次の文を完成させます。

> 私はふだん＿＿＿＿しやすい。それは＿＿＿＿という強みを持つ。同時に、＿＿＿＿という条件では、＿＿＿＿を一回することもできる。

その文は、新しいタイプ名ではありません。

あなたが現実の中で手に入れた、一つ多い選択肢です。
