# 书末练习　30 天，增加一个选择

本工作的目标，并非改变类型。

30 天后，在某个特定的场景中，能够选择一种不同于往常的反应。这就是目标。

不需要进行所有练习。只需针对一个现实中的问题，用 30 天的时间小步处理。

请根据你可用于记录的时间，从以下两种方式中选择一种。

## Lite 版：每日一分钟的四个问题

如果每天详细记录让你感到负担，只需回答接下来的四个问题。

1. 今天发生了什么？
2. 我下意识地想要怎么做？
3. 尝试了另一种行动吗？
4. 实际上发生了什么？

“没有尝试”也是一种记录。每周只需重新审视一次未能尝试的理由，以及是否可以将行动变得更小。

也不必每天都做。只要在有目标场景发生的日子里填写即可。

## Deep 版：对比预测与结果的 30 天

当同样的困扰反复出现，且希望详细检视条件与恢复成本时，请使用以下的 Deep 版。

### 0 选定一个处理场景

选择满足以下条件的场景：

- 本月内至少发生过两次。
- 你自己认为结果可以稍作改变。
- 一次小小的实验不会给工作、收入、健康、安全或重要的人际关系造成无法恢复的损害。
- 并非由他人强制要求的变化。

例如，类似以下的场景：

- 会议上虽有想法，却直到结束也未发言。
- 倾听对方说话时，立刻提出解决方案。
- 每当有新点子浮现就改变计划，导致一事无成。
- 即使看到与最初计划不符的信息，也无法做出更改。
- 从一次失败便得出结论：“这份工作不适合我的类型”。

### 我选定的场景

> 当＿＿＿＿发生时，我平时会＿＿＿＿。其结果，容易引发＿＿＿＿。

### 第 1 周：发现

第一周不进行任何改变。

每当同一场景出现时，记录以下五项内容：

1. **合图**：紧接着发生了什么？
2. **行动**：自己用可观察的语言做了什么？
3. **身体反应**：紧张、疲劳、速度、沉重感如何？
4. **短期利益**：该行动保护了什么？
5. **后续代价**：数分钟后、数小时后或数日后留下了什么？

将“消极”、“优柔寡断”、“冷漠”等评价性词汇转化为具体行动。

- 消极 → 有了提问的念头，但在会议中未开口。
- 优柔寡断 → 直到申请截止日期前两天仍在比较候选者。
- 冷漠 → 在对方讲述困境缘由前，便说明了解决步骤。

第一周的成功，不在于改变。

只要能说出“何时、在何种条件下、正在做什么”，哪怕只有一次，即为成功。

### 第 2 周：重新审视

第二周，调查该场景中缺失的部分。

请不要按照自己的类型来回答。请逐一检视以下八项：

| 方向 | 问题 |
|---|---|
| 外 | 应从本人、现场或他人处获取什么信息？ |
| 内 | 能否脱离周围反应，独自思考一段时间？ |
| 事实 | 是否区分了已确认的内容与推测？ |
| 可能性 | 是否还有未曾考虑的解释、方法或未来？ |
| 原则 | 依据什么标准做决定？相同条件是否能得出相同解释？ |
| 影响 | 谁会受到何种影响？是否听取了本人的意见？ |
| 收敛 | 需要在何时之前决定什么？ |
| 余白 | 有哪些事项可暂不决定，依据哪些信息重新审视？ |

从这八项中，选出该场景中最为缺失的一项。

> 在此场景中，缺失的或许是＿＿＿＿的信息/行动。

这并非结论，而是假设。

### 第 3 周：小步尝试

第三周，将缺失的部分转化为一次具体行动。

良好的实验需满足以下五项条件：

- **微小**：可缩减至 15 分钟以内、一句话、一个人或一次。
- **可观察**：不是“努力”，而是能否判定是否执行了某事。
- **有合图**：明确何时执行，设定情境。
- **可逆**：根据结果调整下一次的行动方式。
- **出于己愿**：非基于类型论或他人强制的行动。

### 转化为 if-then

> 如果＿＿＿＿这一合图出现，我就进行一次＿＿＿＿。

例如：

- 如果主持人在第一个议题后征求意见，我就读出准备好的那句话。
- 如果倾听对方后浮现了解决方案，在说出之前先问：“现在想听我说？还是想一起解决？”
- 如果想到新点子，先将当前最低版本推进 15 分钟后再记录。
- 如果收到与计划不符的信息，将其加入下次复查用的对比表中。

初次尝试时，将难度降至满分 10 分中的 3–4 分。

若执行不顺，不要归结为“意志薄弱”，而应检查行动是否过大，或合图是否模糊。

### 第 4 周：重新编织

第四周，不以“成功/失败”来给自己打分，而是将结果重新编织进行动的广度之中。

### 一次实验记录

| 项目 | 记录内容 |
|---|---|
| 场景 | 何时、何地、与谁、发生了什么 |
| 预测 | 认为采取行动后会怎样 |
| 执行 | 是否完成了决定的小行动 |
| 事实 | 实际看到或听到的内容 |
| 体验 | 心情、紧张感、疲劳度及恢复情况如何 |
| 他人反应 | 直接听到的反馈是什么。是否区分了推测与事实 |
| 差异 | 预测与现实有何不同 |
| 下次 | 保留什么、缩小什么、改变什么 |

即使一次成功，也需再次确认该行动在何种条件下可用。

若未成功，切勿将其作为类型的证明：

- 行动是否过大？
- 传达方式是否不合对方心意？
- 对该场景所需能力的假设是否错误？
- 是否忽略了性格以外的条件，如风险、权限、时间或健康状况？

利用这些信息，重新组合下一次尝试。

### 30 天后的回顾

回答以下六个问题：

1. 在何种条件下，容易流露出往常的反应？
2. 往常的反应保护了什么？
3. 需要采取相反行动的条件是什么？
4. 在新行动中，哪些可延续至下次使用？
5. 有哪些事项可暂不使用、交由他人或寻求支援？
6. “我因为＿＿所以做不到”这句话，现在该如何改写？

最后，完成以下句子：

> 我平时容易＿＿＿＿。这源于我拥有＿＿＿＿这一优势。同时，在＿＿＿＿的条件下，我也能进行一次＿＿＿＿。

这句话并非新的类型名称。

这是你在现实中获得的、多出的一个选项。
