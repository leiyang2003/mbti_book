# 第 8 章　S 与 N——看见事实的力量，看见可能性的力量

悠人的企划书，总是让人心潮澎湃。

为什么现在需要这个？三年后能创造出怎样的世界？与其他服务有何不同？故事极具感染力，让听众感到兴奋不已。

会议结束时，总有人问道：

“那么，第一周具体要做什么呢？”

一旦听到这个问题，悠人便会再次开始讲述新的可能性。答案尚未可知。

也有相反的情况。

过去的数字、客户的需求、现行的流程都了如指掌。然而，当被问及“如果条件发生变化怎么办？”或“现在的客户尚未言明的需求是什么？”时，那些缺乏实绩的构想便显得不切实际。

看见事实的力量，与看见可能性的力量。

S 与 N，正是思考这两者的入口。

若只偏重一方，要么被现实绊倒，要么脱离现实。

## S 不只意味着关注细节，N 也不等于天才

在四个字母文化中，S 常被描绘为现实且细致的人，N 则被描绘为富有想象力且聪慧的人。

这种描绘方式中，早已隐含了价值判断的差异。

实际上，准确观察具体事实的能力，与捕捉无形关联及可能性的能力，同样属于高阶能力。

无论偏好哪个字母，观察都可能粗糙，也可能充满创造力。

S/N 的提问所探讨的，广义而言，是我们在接收信息时更容易将注意力投向何处。这并非智力或创造力的排序。

“因为是 S 所以缺乏发想力”、“因为是 N 所以无法处理实务”，这是从偏好直接跳跃到能力的谬误。[注 2]

## 从 N 走向 S——让构想落到今天的现实中

善于看见可能性的人，会将尚未存在的事物化为语言。

他们从眼前的事件中读出模式，发现别样的意义；将遥远离散的点子连接起来，描绘未来的图景。

然而，可能性是无限的。

每发现一个新的关联，方针就可能随之改变。解释变得庞大，行动却因此迟缓。若将细节推给“稍后由他人处理”，最终留下的往往是无法实现的构想。

S 侧的力量，并非为了缩小梦想。

它的存在，是为了搭建梦想与现实接触的触点。

### 最小的一步：三个事实与今日的一步

当构想或烦恼变得庞大时，将纸分为两半。

左侧，写下此刻可确认的三个事实：

- 数字、日期时间、对方实际说出的话语。
- 已存在的资源。
- 今日的限制条件。

右侧，写下 24 小时内可行的一步行动。

不必完成全部调查，只需询问一人；不必完成服务成品，只需展示纸面原型；不必决定人生方向，只需与候选职业者交谈 20 分钟。

事实并不否定想象。

它指明了想象接下来能触碰的地面。

当时，悠人写下了手边可确认的三个事实：有两位愿意倾听的潜在客户；他们共同困扰的作业只有一项；在纸面上，今日即可构建该作业流程。

他并未制作成品，而是向其中一人展示了纸面原型。对方几乎未关注悠人认为重要的功能，却在另一个地方停下了动作。

这并非失败。那是他的构想首次收到现实回应的瞬间。

## 从 S 走向 N——仅凭过去的事实，无法读懂变化

重视具体信息的人，支撑着现实。

他们铭记实际发生的事件，复现流程，守护品质；为仅有文字描述的企划赋予必要的时间与费用。

然而，事实是关于过去与现在的信息。

它不会直接告知条件已改变的未來。

“没有先例”并不等同于“做不到”。“客户未提出要求”并不会抹杀“尚未被想象到”的可能性。

此外，单一事件往往存在多种解释。

同事没有回复邮件：是因为忙碌？表示反对？未曾阅读？还是问题表述不明？事实仅仅是“没有回复”。

N 侧的力量，并非逃避现实的空想。

它是赋予事实中尚未确定的意义至少一种的能力。

### 最小的一步：三种不同的解释

当似乎要从一个事实直接得出结论时，写下另外三种解释：

> 发生的事实：＿＿＿＿。
> 解释 A：＿＿＿＿。
> 解释 B：＿＿＿＿。
> 解释 C：＿＿＿＿。

三者无需全部正确。

目的是不要将第一种解释视为绝对事实。

若是企划，思考除当前用法外的三种用途；若是职业，思考将现有技能应用于其他行业的三条路径。

研究表明，发散性思维生成与创造力可在一定程度上通过训练提升。但需注意，在创造力测试中方案数量的增加，并不必然转化为现实中的创新成果。[注 1]

因此，最终仍需将构想回归事实。

先验证哪一种解释，又用什么方式验证？

## 不在同一栏书写事实与解释

调整 S 与 N 偏向的简单方法，在于区分事实与解释。

### 事实

可被录音、记录或观察者大致确认的内容。

“会议上对我的提案提出了两个问题。”

### 解释

赋予事实的意义。

“大家是在反对我的方案。”

### 可能性

尚未发生但可设想的展开。

“若能回答这些问题，方案或许能得到改善。”

### 下一步确认

使解释或可能性接触现实的行动。

“向提问者询问其最大的担忧之一。”

将这四者区分开来，S 与 N 便不再相互竞争。

事实不会封闭想象，想象也不会无视事实，从而形成良性循环。

## 从过去学习，而非被过去束缚

无论何种类型，我们皆依赖经验。

经验是避免重复失败的智慧。

然而，经验越丰富，“以前也这样”的惯性便越容易支配新情境。

要从过去中学习，需要两个追问：

“与上次相同的条件是什么？”

“与上次不同的条件是什么？”

仅关注相同条件，可能性便会消失；仅关注不同条件，教训也会落空。

S 与 N 的往复，并非在“过去”与“未来”之间做选择。

而是带着过去的具体性，去思考尚未到来的未来。

## 小实验：三个事实，三种不同的解释

此刻，选定一个你正在决断的问题：

1. 写下可确认的三个事实。
2. 为这些事实写下三种不同的解释。
3. 确定一项能在 24 小时内完成的行动，用来验证最重要的那一种解释。

若事实不足，便去收集；若可能性单一，便去拓展。

最后，付诸行动。

看见现实的力量，与超越现实看见可能性的力量。

让两者来回往复，构想就不会停留在梦想之中，事实也不会只是昨天经验的简单重复。
